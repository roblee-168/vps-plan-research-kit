# VPS plan evidence checklist

Record the official URL and UTC date for each claim. Write "Not specified" for unavailable terms.

| Field | What to record |
|---|---|
| CPU | Dedicated or shared, core count, fair-use limits |
| Memory | RAM and swap separately |
| Storage | Capacity, media, redundancy and backup exclusions |
| Transfer | Included transfer, port speed and overage price separately |
| Location | Available region for the selected plan |
| Initial charge | Currency, full upfront commitment and initial term |
| Renewal | Explicit renewal charge and billing period |
| Taxes and fees | Setup, tax, control panel and license charges |
| Credits | Eligibility, expiration, eligible services; never call credits a hosting price |
| Cancellation | Deadline, cancellation mechanism and refund exclusions |
| Operations | Backup restore process, support scope and acceptable-use terms |
| Evidence | Official URL, date, exact relevant wording or a short factual note |

Do not label unlike shared and dedicated CPU plans as equivalent. A money-back guarantee is not an unconditional free trial. Do not assume renewal equals introductory price. Before purchase, verify the final checkout terms yourself.
